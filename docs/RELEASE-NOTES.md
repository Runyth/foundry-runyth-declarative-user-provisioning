# Release Notes — 1.0.0

Declarative User Provisioning introduces a conservative, reviewable desired-state workflow for known Foundry world users. Its stable-key ownership model supports creation, explicit adoption, managed updates, and reversible role-based disablement while preserving unmanaged accounts and document identity.

The first release includes an ApplicationV2 dashboard, versioned public API, English/German localization, strict JSON/YAML validation, offline CLI workflows, deterministic packaging, and lockout protections. It has no game-system or module dependency.
